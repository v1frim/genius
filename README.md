# 🧠 ГЕНІЙ — особистий тренажер геніальності

Сайт-тренажер для щоденного розвитку: увага, швидкочитання, друк, дикція, усний рахунок, пам'ять, медитація — плюс трекер цілей і щоденних задач. Працює повністю офлайн, без сервера та реєстрації.

## Запуск

Варіант 1 — просто відкрий `index.html` у браузері.

Варіант 2 — локальний сервер (надійніше для шрифтів):

```bash
npx serve .
# або
python3 -m http.server 8000
```

Варіант 3 — GitHub Pages: Settings → Pages → Deploy from branch → обери гілку і корінь `/`. Сайт буде доступний з телефона будь-де.

## Дані

Весь прогрес лежить у `localStorage` браузера (ключ `genius.v1`). Це означає:

- нічого нікуди не надсилається, все приватне;
- прогрес прив'язаний до конкретного браузера на конкретному пристрої;
- **періодично роби експорт** на сторінці «Дані», щоб мати резервну копію.

## Структура коду

```
index.html          — каркас і підключення скриптів
css/style.css       — вся тема (фіолетова, у стилі logiclike)
js/store.js         — стан, localStorage, рекорди, перенесення дня/тижня
js/ui.js            — хелпери: елементи, тости, спарклайни, звук
js/data.js          — контент: тексти, скоромовки, банки генератора, задачі та цілі за замовчуванням
js/modules/*.js     — кожен тренажер = окремий незалежний модуль
js/app.js           — роутер і навігація
```

Новий тренажер додається так: створи `js/modules/мій.js` за зразком будь-якого модуля (об'єкт з `id`, `title`, `icon`, `render(root)`), підключи в `index.html` і додай у список `MODULES` в `js/app.js`.
