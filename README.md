# 🧠 Genius — особистий тренажер геніальності

Сайт-тренажер для щоденного розвитку: увага, швидкочитання, друк, дикція, усний рахунок, пам'ять, медитація — плюс трекер цілей і щоденних задач. Працює повністю офлайн, без сервера та реєстрації.

## Встановити як застосунок (PWA)

Сайт можна поставити на телефон як звичайний застосунок — повноекранно, з іконкою, працює офлайн:

- **iPhone (Safari):** відкрий сайт → «Поділитися» → «На початковий екран».
- **Android (Chrome):** меню → «Встановити застосунок» (або банер «Додати на головний екран»).

Оновлюється автоматично: коли є інтернет, застосунок завжди вантажить найновішу версію сайту (service worker кешує файли лише як запасний варіант для офлайну).

## Запуск

Варіант 1 — просто відкрий `index.html` у браузері.

Варіант 2 — локальний сервер (надійніше для шрифтів):

```bash
npx serve .
# або
python3 -m http.server 8000
```

Варіант 3 — GitHub Pages: Settings → Pages → Deploy from branch → обери гілку і корінь `/`. Сайт буде доступний з телефона будь-де.

## Дані

Весь прогрес лежить у `localStorage` браузера (ключ `genius.v1`). Це означає:

- нічого нікуди не надсилається, все приватне;
- прогрес прив'язаний до конкретного браузера на конкретному пристрої;
- **періодично роби експорт** на сторінці «Дані», щоб мати резервну копію.

### Інтеграція з Oxford 1000 (англійська)

Сайт [Oxford 1000](https://v1frim.github.io/Oxford_1000/) — це теж GitHub Pages того самого користувача, тож обидва сайти живуть на одному origin (`v1frim.github.io`) і **ділять спільний `localStorage`**. Завдяки цьому `js/oxford.js` напряму читає прогрес Oxford (`oxford_days_v1`, `oxford_duolingo_v1`, `oxford_lingohut_v1`) і рахує ту саму шкалу «планів», що й термометр там:

- **1 план = 4 бали** (ігри + сесії Duolingo + уроки LingoHut за день);
- щоденний трекер «Англійська: 2 плани» показує `X/2` і зараховується при 2 планах (8 балів);
- щотижневий трекер «14 планів» показує `X/14` — накопичує плани за тиждень (можна надолужити пропущений день).

Працює в межах одного браузера/пристрою (бо це спільне сховище). Дані Oxford залишаються лише на боці Oxford — genius їх тільки читає.

## Структура коду

```
index.html          — каркас і підключення скриптів
css/style.css       — вся тема (фіолетова, у стилі logiclike)
js/store.js         — стан, localStorage, рекорди, перенесення дня/тижня
js/oxford.js        — інтеграція з Oxford 1000: читає спільний localStorage, рахує «плани»
js/ui.js            — хелпери: елементи, тости, спарклайни, звук
js/data.js          — контент: тексти, скоромовки, банки генератора, задачі та цілі за замовчуванням
js/data.prose.js    — корпус художніх уривків для RSVP (масштабується до сотень)
js/modules/*.js     — кожен тренажер = окремий незалежний модуль
js/app.js           — роутер і навігація
```

Новий тренажер додається так: створи `js/modules/мій.js` за зразком будь-якого модуля (об'єкт з `id`, `title`, `icon`, `render(root)`), підключи в `index.html` і додай у список `MODULES` в `js/app.js`.
