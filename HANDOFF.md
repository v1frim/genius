# HANDOFF — «ГЕНІЙ», тренажер геніальності

Стан на 2026-06-10. Усе описане нижче змерджено в `main` і задеплоєно.

## Що це

Особистий сайт-тренажер користувача (v1frim) для щоденного розвитку: увага, швидкочитання,
друк, дикція, усний рахунок, пам'ять, медитація + трекер цілей і щоденних задач.
Повністю статичний (HTML/CSS/JS без збірки), працює офлайн, дані в localStorage.

- **Репозиторій**: https://github.com/v1frim/genius
- **Сайт**: https://v1frim.github.io/genius/ (GitHub Pages, deploy from branch `main`, root `/`)
- **Мова UI**: українська. Тема: фіолетова, у стилі logiclike.com (referenced користувачем як зразок).

## Робочий процес (домовленості з користувачем)

1. Розробка ведеться в гілці **`claude/ecstatic-goodall-3xlglc`** → push → PR у `main` → merge.
2. **Користувач дав дозвіл самостійно створювати і мерджити PR** («даю добро»).
3. Після мерджу Pages перебудовується автоматично за ~1 хв (workflow «pages build and deployment»).
4. Користувач надсилає скриншоти із зауваженнями → виправляємо ітеративно.
5. Кожна зміна перевіряється Playwright-тестами перед пушем (див. «Тестування»).

Історія PR: #1 початковий сайт · #2 фікси Шульте · #3 RSVP-квіз+Вікіпедія, Шульте СТОП/кольори
· #4 око в центрі · #5 проза+5 кольорів рівнів · #6 більша таблиця + рерайт друку · #7 Space/Tab + cloze-квіз + 93 уривки.

## Архітектура

```
index.html          — каркас, підключення скриптів по порядку (без модулів/збірки)
css/style.css       — уся тема; CSS-змінні в :root; класи tier-* для 5 рівнів оцінки
js/store.js         — стан + localStorage (ключ genius.v1), rollover дня/тижня, рекорди
js/ui.js            — h() створення DOM, тости, спарклайни (SVG), beep (WebAudio), shuffle/rnd
js/data.js          — задачі/цілі за замовчуванням, скоромовки + банки генератора,
                      тексти для друку (UA панграми + EN), 5 текстів для тесту читання з питаннями
js/data.prose.js    — корпус художніх уривків для RSVP (зараз 93; нарощувати батчами тут)
js/modules/*.js     — кожен тренажер = модуль {id, title, icon, render(root) → cleanup()}
js/app.js           — роутер (#/id), навігація, глобальні клавіші Space/Tab, App.primaryAction
```

Патерн модуля: `render(root)` будує DOM через `App.ui.h`, повертає `cleanup` (зняти інтервали/лісенери).
Новий модуль: створити файл, додати `<script>` в index.html, додати в `MODULES` в app.js.

### Ключові механіки

- **store.rollover()**: при зміні дати — вчорашні щоденні задачі йдуть в `taskHistory` (pct),
  чекбокси скидаються; щотижневі скидаються по понеділках. Викликається при кожній навігації.
- **Стрік**: день зараховано при ≥70% щоденних задач (PASS_PCT у dashboard.js).
- **Цілі з auto**: рекорди підтягуються в цілі (reading тест wpm, typing cpm, медитації count/max,
  digit span, visual matrix). `autoMode: "max"` → max(base, авто); `"count"` → base + кількість.
  RSVP-записи НЕ впливають на рекорд читання (поле `wpm` тільки у kind:"test"; у RSVP — `avgWpm`).
- **App.primaryAction**: модуль реєструє функцію → глобальний Space її викликає (старт гри).
  Скидається роутером при навігації. `stopImmediatePropagation` щоб старт-Space не паузив RSVP.
  Tab/Shift+Tab — перемикання розділів (perventDefault на Tab глобально).

### Специфічні рішення в модулях

- **Шульте**: сітка 620px (~90% logiclike), шрифт `calc(var(--fs) * 1cqw)` пропорційний клітинці.
  На непарних розмірах центральна клітинка = око (SVG, EYE_SVG), чисел n²−1; на парних — око-накладка
  `.center-eye`. Знайдені числа затемнюються (не зникають). Кнопка СТОП. Оцінка evaluate():
  пороги n*0.8/1.2/1.8/2.6 c → класи tier-elite/great/good/mid/slow (5 різних кольорів).
  Орієнтири рендеряться стовпчиком під вибраний розмір. Режими: перемішування після кліку (s),
  зворотний (r); ключ режиму — рядок "s"/"r"/"sr"/"".
- **Швидкочитання (RSVP)**: джерела — «Художні» (дефолт, з data.prose.js, склейка випадкових
  уривків до довжини s/m/l = 130/280/550 слів) та «Вікіпедія» (uk.wikipedia.org REST
  /page/random/summary, батчами по 4, фільтр заглушок <20 слів). ORP (червона літера-якір) —
  опція, вимкнена за замовчуванням (слова просто по центру — прохання користувача).
  Плейсхолдер «приклад» показує розмір шрифту наживо. Після тексту — квіз: рівно 3 питання,
  типи: пізнавання речення, cloze «яке слово пропущено» (дистрактори зі схожим закінченням
  з невикористаних уривків), число-пропуск (запасний), заголовок (лише вікі). Питання
  «яке слово траплялося» видалено як слабке. comp зберігається в запис; ефективна швидкість = wpm×comp.
  «Тест швидкості» (вкладка) — 5 вбудованих текстів із ручними питаннями; тільки він дає рекорд.
- **Клавотренажер**: друк «крізь помилки» — хибний символ червоний, виправлення Backspace,
  фініш лише коли все правильно. Нормалізація: ґ↔г, усі тире → "-", всі апострофи → "'",
  лапки «»„“ → '"'. Введення через keydown на прихованому input (input-події глушаться).
  Таймер на паузі коли фокус втрачено (accumMs + runStart). Короткий свій текст не підміняється.
- **Скоромовки**: 38 у колекції + генератор з алітераційних банків (15 літер).
- **Арифметика**: 5 рівнів, операції +−×÷ (chips), режими спринт 60/120, 20 прикладів, без ліміту.
- **Пам'ять**: digit span (адаптивний, 10 раундів, прямий/зворотний) + зорова матриця (3 життя).
- **Медитація**: пейсер (бокс 4-4-4-4, сон 4-7-8, когерентне 5-5, свій), таймер сесій,
  журнал (+ ручне додавання), прогрес до 1000 медитацій і 180 хв.
- **Дані**: експорт/імпорт JSON, повне скидання.

## Тестування

Інструменти в контейнері: node v22, playwright (глобально, `/opt/node22/lib/node_modules/playwright`,
chromium у `/opt/pw-browsers`), http-server. Зовнішня мережа з контейнера ЗАКРИТА (allowlist) —
Вікіпедія тестується перехопленням `page.route('**/api/rest_v1/page/random/summary')` з моком.

Схема перевірки перед пушем:
1. `node --check` на кожен змінений js-файл.
2. Node-smoke логіки store/data зі стабами window/localStorage.
3. Playwright-сценарії: підняти `npx http-server -p 8123`, проклацати модуль як користувач,
   перевірити localStorage-записи і відсутність pageerror. Кирилицю вводити НЕ через
   keyboard.type (не шле keydown), а dispatchEvent(new KeyboardEvent('keydown', {key})).
Тестові скрипти жили в /tmp (ефемерні) — за потреби писати заново за цією схемою.

## Контекст користувача (для тону і пріоритетів)

Будує «геніальність»: швидкочитання 400+ сл/хв (зараз ~150–180), друк 400+ зн/хв (~250–300),
шахи FIDE 1400–1600 (тренує на chess.com — свідомо зовнішнє), харизма (YouTube Charisma on Command),
медитація (ціль 1000 сесій, 3 год за раз), усвідомлене дихання протягом дня, англійська C1
(трекає на окремому сайті — обіцяв скинути приклади), 500 книг, спорт-цілі тощо.
Усі цілі заведені на сторінці «Цілі» + 12 рекомендованих (digit span 9+, журнал Шерлока,
π-100, колода карт, есе, виступи, сон, задачі 2000, холодний душ, жонглювання).
